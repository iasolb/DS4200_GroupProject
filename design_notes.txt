Design Notes
Project: Mapping Urban Change Through 311 Service Requests

Published website link:
https://iasolb.github.io/DS4200_GroupProject/

General design idea:
We wanted the website to feel like one connected story about how Boston 311 patterns changed from 2015 to 2025. The figures start with overall neighborhood change, then move into maps, cluster patterns, neighborhood comparisons, seasonality, and tract-level validation. We kept the webpage style simple so the figures stand out and feel consistent.

Figure 1: Neighborhood Signature Drift Quantification
This figure shows which neighborhoods changed the most from 2015 to 2025. Sorting the bars by drift makes the ranking easy to read, and the median reference line shows which neighborhoods are above the typical level of change.

Figure 2: Interactive Side-by-Side Geographic Map
The map shows where requests are located across Boston. Side-by-side maps make the two years easier to compare, and clickable markers let viewers inspect individual records.

Figure 3: Neighborhood Cluster Profiles
This figure shows how neighborhoods group together based on similar complaint patterns. The 2015 and 2025 cluster profiles are shown separately so viewers can compare how neighborhood groupings changed over time.

Figure 4: Neighborhood Request Composition Analysis
We used horizontal grouped bars because the request type names are long and because the main goal is comparing 2015 and 2025 side by side. The year colors make the comparison clear.

Figure 5: Interactive Neighborhood Request Pattern Comparison
This figure is for closer inspection of one neighborhood at a time. The dropdown lets the viewer focus on a specific neighborhood, and the legend interaction helps compare years more easily.

Figure 6: Seasonal Patterns in 311 Requests
This heatmap shows seasonal request patterns. We used a grid because it makes monthly patterns easy to compare, especially winter-related request types. The takeaway also notes that some differences may reflect category changes in the 311 records.

Figure 7: Tract-Level Socioeconomic Validation
This D3 scatter plot compares tract-level socioeconomic measures with complaint outcomes. The x-axis dropdown switches between poverty rate and median household income, the y-axis dropdown changes the complaint metric, hover shows tract details, and clicking a point pins it. Point size shows population and point color shows income.

How the figures connect:
The figures are not meant to be separate. Figure 1 introduces which neighborhoods changed most, Figure 2 shows where requests are located, Figures 3 and 4 explain neighborhood-level patterns, Figure 5 lets the user explore specific neighborhoods, Figure 6 explains seasonal/category changes, and Figure 7 checks whether the story also appears at the tract level.
